# BluetoothStudio

**BluetoothStudio** — мобильное Android-приложение для поиска, подключения и взаимодействия с Bluetooth Low Energy (BLE) устройствами.

Проект разработан в рамках дипломной работы и предназначен для упрощения работы с BLE-устройствами: сканирования окружения, подключения к устройствам, просмотра GATT-сервисов и характеристик, чтения и записи данных, а также анализа событий через встроенную консоль логов.

## Актуальность проекта

BLE-устройства широко применяются в IoT, носимой электронике, медицинских датчиках, умном доме и промышленной автоматизации. При разработке и отладке таких устройств часто требуется быстро проверить доступные сервисы, характеристики, значения и состояние соединения.

BluetoothStudio решает эту задачу, предоставляя мобильный инструмент для базовой диагностики и взаимодействия с BLE-периферией без необходимости писать отдельный тестовый клиент под каждое устройство.

## Основные возможности

- Поиск BLE-устройств поблизости.
- Отображение имени устройства, MAC-адреса и уровня сигнала RSSI.
- Подключение к выбранному BLE-устройству.
- Просмотр активных подключений.
- Отображение состояния подключения.
- Обнаружение GATT-сервисов и характеристик.
- Распознавание стандартных сервисов и характеристик Bluetooth SIG.
- Чтение значений характеристик.
- Запись данных в характеристики.
- Встроенная консоль логов.
- Отображение технической информации о событиях подключения, чтения и записи.
- Настройка отображения временных меток в логах.
- Поддержка русской и английской локализации.

## Архитектура проекта

Проект разделён на несколько Gradle-модулей:

```text
BluetoothStudio/
├── app/       # UI, навигация, ViewModel, DI
├── data/      # Реализация BLE, DataStore, логирование, загрузка спецификаций
├── domain/    # Бизнес-логика, интерфейсы, модели, use case
├── core/      # Общие классы Result, Error, сериализаторы
└── gradle/    # Gradle wrapper и версии зависимостей
```

Приложение построено с разделением ответственности:

- **presentation** — экраны, компоненты интерфейса, навигация;
- **domain** — модели, use case, интерфейсы репозиториев и BLE-компонентов;
- **data** — работа с Android BLE API, реализация репозиториев, загрузка данных Bluetooth SIG;
- **core** — общие утилиты и базовые типы результата выполнения операций.

## Основные экраны

### Экран сканирования

Позволяет запускать и останавливать поиск BLE-устройств. Найденные устройства отображаются списком с именем, MAC-адресом и уровнем сигнала RSSI.

### Экран подключений

Показывает активные подключения к BLE-устройствам. Пользователь может открыть подключение, просмотреть состояние или удалить выбранные соединения.

### Экран устройства

Отображает информацию о подключённом устройстве, список GATT-сервисов и характеристик. Для стандартных UUID используются названия из спецификации Bluetooth SIG.

### Экран характеристики

Позволяет работать с конкретной характеристикой BLE-устройства. В зависимости от доступных свойств характеристики отображаются вкладки:

- `Read` — чтение значения;
- `Write` — запись значения;
- `Notify` — заготовка для дальнейшей реализации уведомлений.

### Консоль

Содержит журнал событий приложения: подключение, отключение, ошибки GATT, чтение и запись характеристик. Для логов отображаются тег, сообщение, адрес устройства, UUID сервиса/характеристики и переданные данные.

### Настройки

Содержит пользовательские настройки приложения. На текущем этапе реализовано включение и отключение временных меток в консоли логов.

## Работа с BLE

BluetoothStudio использует стандартный Android BLE API:

- `BluetoothLeScanner` — поиск устройств;
- `BluetoothGatt` — подключение и работа с GATT;
- `BluetoothGattCallback` — обработка событий подключения, обнаружения сервисов, чтения и записи;
- `BluetoothGattCharacteristic` — работа с характеристиками.

Для работы приложения требуются разрешения:

```xml
BLUETOOTH_SCAN
BLUETOOTH_CONNECT
BLUETOOTH_ADMIN
ACCESS_COARSE_LOCATION
ACCESS_FINE_LOCATION
```

## Справочник Bluetooth SIG

В проект встроены YAML-файлы со стандартными UUID сервисов и характеристик Bluetooth SIG:

```text
app/src/main/assets/specification/bluetooth_sig/assigned_numbers/uuids/
├── service_uuids.yaml
└── characteristic_uuids.yaml
```

Они используются для отображения человекочитаемых названий стандартных сервисов и характеристик вместо одних только UUID.
